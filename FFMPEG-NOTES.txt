Bundled FFmpeg
==============

This Shrinkr archive ships FFmpeg binaries (ffmpeg, ffprobe) next to
the application so it works out of the box — no system-wide FFmpeg
installation required.

These are unmodified static builds downloaded from the following
upstream projects. Every download — at release time and for the
in-app "Download FFmpeg" button on Windows — is pinned and verified
against FFMPEG-PINS.sha256 before anything is unpacked or run:

  Windows x64 : FFmpeg-Builds N-128889-g88c46fce27 master autobuild
                (tag autobuild-2026-11-13-12-43), GPL build
                github.com/FFmpeg-Builds/FFmpeg-Builds
  Linux x64   : same build as the Windows pin, GPL build
  macOS arm64 : ffmpeg / ffprobe 9.0.2 from www.osxexperts.net
                (GPL build)

FFmpeg is an open-source project: https://ffmpeg.org
This build is licensed under the GNU General Public License — see
https://ffmpeg.org/legal.html and the upstream project pages above
for source code, versions, and license texts. Shrinkr launches these
binaries as separate processes and does not modify them.

Bumping the pinned builds
-------------------------
Update FFMPEG-PINS.sha256 (procedure in its header), the pinned tag /
asset constants in .github/workflows/release.yml and
core/src/ffmpeg_fetch.rs, and the version notes above — all four in
the same commit, so release builds and runtime downloads stay in sync.
